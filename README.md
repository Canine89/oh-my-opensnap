<h1 align="center">oh-my-opensnap 📸</h1>

빠르고 정밀한 **macOS 화면 캡처 도구**. 영역이나 창을 픽셀 단위로 집어 캡처하고, 곧바로 클립보드에 복사하고, 캡처본을 라이브러리에 모아 주석·크롭·영상 편집까지 한 곳에서.

> macOS 26 (Tahoe) 이상 · 메뉴 막대 상주 · 무료 / 오픈소스 · 한국어 / English

## 왜 만들었나

저는 **9년째 IT 도서를 기획하고 편집**하는 편집자입니다. 하루에 화면 캡처만 **500장, 많을 땐 1,000장**을 찍습니다. 캡처는 제 일의 절반입니다.

그래서 좋은 캡처 프로그램이라면 **돈을 주고서라도** 써 왔습니다. 캡처 속도·정밀함·뒷정리가 곧 제 생산성이니까요.

이제는 매일 수백 장을 찍는 사람의 손에 맞춘 그 도구를 **직접 만들어, 무료로 배포**합니다. 그게 oh-my-opensnap입니다.

---

## 📥 설치

Homebrew를 쓴다면:

```bash
brew tap canine89/oh-my-opensnap https://github.com/Canine89/oh-my-opensnap
brew trust canine89/oh-my-opensnap
brew install --cask oh-my-opensnap
```

직접 내려받아 설치하려면:

1. [**Releases**](../../releases/latest) 에서 최신 `.dmg` 파일을 받습니다.
2. `.dmg` 를 열고 **`oh-my-opensnap` 아이콘을 `Applications` 폴더로 드래그**합니다.
3. `Applications` 폴더에서 앱을 실행합니다.
4. 첫 캡처 때 뜨는 **화면 녹화 권한**을 켭니다
   (시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹화 → `oh-my-opensnap` ON).

> 앱과 DMG는 Apple Developer ID로 서명되고 공증되어 배포됩니다. 일반적인 설치 과정에서는 “확인되지 않은 개발자” 우회가 필요하지 않습니다.

> 그림과 함께 한 단계씩 따라 하려면 👉 [INSTALL.md](INSTALL.md)

> 기본 언어는 영어입니다. 한국어로 쓰려면 첫 실행 안내 팝오버 또는 **설정 → 일반 → Language · 언어**에서 한국어를 고르세요(즉시 적용).

배포는 **Developer ID 서명·Apple 공증 + Sparkle 자동 업데이트**로 통일되어 있습니다. 설치 후에는 앱이 **자동으로 업데이트를 확인**합니다(Sparkle). 새 버전이 나오면 알림이 뜨고 클릭 한 번으로 갱신됩니다. 메뉴바 → **업데이트 확인…** 으로 수동 확인도 가능합니다.

## ✨ 주요 기능

- **정밀 영역 캡처**: 전체 화면 디밍 + 크로스헤어 + 라이브 확대경(픽셀 격자·좌표·HEX 색상), 실시간 W×H(px)·Retina 배율 표시
- **창 스냅**: 창 위로 커서를 옮기면 창 전체 / 본문 구역이 하이라이트되고 클릭 한 번으로 그 창만 캡처
- **즉시 클립보드 복사** — 캡처와 동시에 붙여넣기 준비 완료. 수백 장을 빠르게 쳐내기 위한 흐름
- **영상 촬영**: 고른 영역을 그대로 MP4로 촬영(일시정지·재개·중지는 메뉴 막대에서). 라이브러리에서 구간을 잘라 MP4 / GIF로 내보내기
- **라이브러리 + 편집기** — 캡처본을 오늘/어제/최근 7일로 모아 보고, 번호·텍스트·말풍선·화살표·도형·모자이크로 표시하거나 크롭·띠 잘라내기
- **첫 실행 안내** — 메뉴 막대 위치·단축키·화면 녹화 권한을 팝오버 하나로 안내
- 멀티 디스플레이 / Retina 대응 · 한국어 / 영어 UI

## 🧭 메뉴 막대 메뉴

메뉴 막대의 카메라 아이콘(📷)을 누르면:

| 메뉴 | 단축키 | 설명 |
|---|---|---|
| **캡처** | `⌘⇧2` | 영역 드래그 또는 창 클릭으로 선택 → `⏎` 이미지 캡처 · `R` 영상 촬영 · `Esc` 취소 |
| **촬영 일시정지 / 중지** | | 영상 촬영 중에만 표시. 아이콘이 빨간 점 + 경과 시간으로 바뀜 |
| **라이브러리…** | `⌘L` | 캡처 보관함 + 편집기 열기 |
| **설정…** | `⌘,` | 일반(단축키·언어·캡처 사운드) / 저장(폴더·파일 옵션) / 권한 / 정보 |
| **업데이트 확인…** | | Sparkle로 새 버전 확인 |
| **시작 안내…** | | 첫 실행 안내 팝오버 다시 보기 |
| **종료** | `⌘Q` | 앱 종료 |

## 🖼 라이브러리 편집기 사용법

`⌘L` 로 라이브러리를 열면 왼쪽에 캡처 목록(썸네일, 오늘/어제/최근 7일/이전), 오른쪽에 미리보기/편집 화면이 나옵니다.
캡처 직후엔 방금 찍은 이미지가 자동으로 선택되고, 창 크기도 이미지에 맞게 조절됩니다.

**편집 도구**

| 도구 | 키 | 설명 |
|---|---|---|
| 🔘 선택 | `V` | 주석을 클릭해 이동, 핸들로 크기 조절. 방향키 1px · `⇧`방향키 10px |
| ✂️ 크롭 | `C` | 드래그로 영역 지정 → `⏎`(또는 완료)로 잘라내기 |
| ↕️ 가로 띠 잘라내기 | | 위아래로 드래그한 구간을 없애고 높이를 줄임 |
| ↔️ 세로 띠 잘라내기 | | 좌우로 드래그한 구간을 없애고 너비를 줄임 |

**주석 도구**

| 도구 | 키 | 설명 |
|---|---|---|
| ➊ 번호 | `N` | 클릭할 때마다 1→9 순서로 동글 번호 |
| 🅃 텍스트 | `T` | 클릭한 자리에 입력 |
| 💬 말풍선 | `B` | 가리킬 곳에서 드래그 |
| ↗️ 화살표 | `A` | 드래그 (`⇧` 45° 스냅) |
| ⬛ 사각형 / ⬭ 원 | `R` / `O` | 드래그 (`⇧` 정사각형·정원) |
| ▦ 모자이크 | `M` | 드래그한 영역을 모자이크로 가림 |
| 🎨 스타일 | | 색상 · 굵기(텍스트 크기). 선택한 주석에도 바로 적용 |

**동작**

| 동작 | 단축키 |
|---|---|
| 되돌리기 / 다시 실행 (크롭도 되돌려짐) | `⌘Z` / `⇧⌘Z` |
| 현재 화면 복사 | `⌘C` |
| 확대 / 축소 / 창에 맞춤 | `⌘+` / `⌘-` / `⌘0` (`⌘`+스크롤도 가능) |
| 휴지통으로 이동 | `⌫` |
| 창 닫기 / 최소화 | `⌘W` / `⌘M` |

- 그리기 도구가 켜져 있어도 기존 주석을 클릭하면 선택·이동. 주석 위에 겹쳐 그리려면 `⌥`+드래그
- 주석은 캡처마다 따로 보관되어 다른 캡처를 보고 돌아와도 그대로 편집할 수 있고, 원본 PNG는 크롭 전까지 손대지 않습니다(복사·저장 시에만 합성)
- 썸네일 **우클릭 → 클립보드에 복사 · 저장 · Finder에서 보기 · 휴지통**
- **영상**은 재생/일시정지(`Space`), 시작점·끝점 지정 후 **내보내기 → 선택 구간을 MP4 / GIF(가볍게 30프레임 · 부드럽게 45프레임)** 로 저장

---

캡처본은 기본적으로 **`~/Library/Application Support/oh-my-opensnap`** 에 PNG로 보관됩니다(설정 → 저장에서 폴더 변경 가능). 예전 버전에서 쓰던 바탕화면 `oh-my-opensnap` 폴더가 있으면 그 위치를 그대로 유지합니다.
