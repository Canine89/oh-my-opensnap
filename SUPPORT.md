# Oh-my-opensnap Support

## Getting started

Oh-my-opensnap is a menu bar app for precise screen captures and recordings on macOS 26 (Tahoe) or later.

1. Launch the app. Its camera icon appears in the menu bar.
2. Use **Command-Shift-2** or choose **Capture** from the menu.
3. The first capture requires macOS **Screen & System Audio Recording** permission.
4. Select an area, then choose an image capture or video recording.

## Common questions

### The app asks for screen recording permission
Open **System Settings → Privacy & Security → Screen & System Audio Recording**, enable Oh-my-opensnap, then relaunch the app if macOS asks you to.

### Where are captures saved?
New installations save captures in Application Support by default. You can choose another folder in **Settings**. Existing installations that use the Desktop folder retain that location.

### How do I change the language?
The app ships in English by default and also supports Korean. Pick a language in the welcome popover on first launch, or later in **Settings → General → Language · 언어**. The change applies immediately.

### How do I close the Library or Settings window?
Press **Command-W** (or **Command-M** to minimize). The app keeps running in the menu bar.

### The menu bar icon is not visible
Oh-my-opensnap is a menu bar app, so it does not appear in the Dock. Look for the camera icon at the top of the screen. If it is hidden by other menu bar icons, make room in the menu bar.

### How can I get help or report a bug?
Please open an issue with your macOS version, app version, and steps to reproduce:
https://github.com/Canine89/oh-my-opensnap/issues
